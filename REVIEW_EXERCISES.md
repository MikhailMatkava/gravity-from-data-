# Проверка ответов AI по физике и математике

Эта часть проекта предназначена для тренировки роли AI-тренера: найти ошибку в коротком объяснении, исправить её понятно для ученика и предложить проверку. Сначала закрой раздел с ответами и попробуй самостоятельно.

## Задание 1: смысл коэффициента

**Ответ модели:** «В регрессии `h = a + b*t + c*t²` ускорение свободного падения равно `c`, значит если `c = -4.9`, то `g = -4.9 м/с²`».

Сформулируй исправление, начиная с уравнения для равноускоренного движения. Объясни множитель 2 и знак.

## Задание 2: выбор признаков

**Ответ модели:** «Квадратичная модель `LinearRegression` не может описать параболу, потому что LinearRegression умеет строить только прямые».

Поясни, в каком смысле регрессия линейна. Укажи форму строки входной матрицы для одного момента времени `t=2`.

## Задание 3: проверка качества

**Ответ модели:** «Мы случайно перемешали все точки траектории и получили хорошую MAE на test, следовательно, модель хорошо предсказывает будущие моменты времени».

Почему вывод не следует из такой проверки? Как разделить данные для поставленной задачи экстраполяции?

## Задание 4: цена идеального результата

**Ответ модели:** «На синтетических данных без шума оценка `g` совпала с 9.81. Значит алгоритм доказал, что ускорение свободного падения в природе всегда равно 9.81».

Раздели проверку корректности кода на искусственных данных и измерение природы. Какие ошибки появятся в реальном эксперименте?

## Задание 5: размер ошибки

**Ответ модели:** «MAE = 0.08, значит модель ошибается в среднем на восемь процентов».

Запиши определение MAE и её единицы измерения в этом проекте. Какие дополнительные данные нужны для процентной метрики?

## Варианты исправлений

**1.** Сопоставим `h(t) = h0 + v0*t - g*t²/2` и `h(t) = a + b*t + c*t²`. Следовательно, `a = h0`, `b = v0`, `c = -g/2`, откуда `g = -2c`. При `c = -4.9 м/с²` получим `g = 9.8 м/с²`. Коэффициент `c` уже имеет размерность ускорения, но его численное значение не равно `g`.

**2.** Метод линейный по искомым параметрам `a`, `b`, `c`. Если заранее сформировать признаки `[t, t²]`, он может описать параболу по `t`. При `t=2` одна строка матрицы признаков — `[2, 4]`; для sklearn её форма `(1, 2)`.

**3.** Случайное перемешивание даст близкие по времени точки в обеих выборках и проверит в основном интерполяцию. Для прогноза будущего возьмём ранний отрезок в train, поздний — в test. Но даже это остаётся оценкой на одной синтетической траектории.

**4.** Синтетическая траектория создана из той же формулы и заданного значения g; восстановление подтверждает работу вычислений в идеальном случае. В природе g меняется с местом измерения; кроме того, будут сопротивление воздуха, погрешности датчика и отклонения от идеальной модели. Для реального измерения нужны независимые данные и оценка неопределённости.

**5.** `MAE = (1/n) * sum |h_pred_i - h_measured_i|`. Высота здесь измеряется в метрах, поэтому MAE = 0.08 **м** — это 8 см средней абсолютной ошибки. Процент зависит от выбранного знаменателя и определения относительной ошибки; его нельзя вывести из одной MAE в метрах. При высотах около нуля относительная ошибка особенно неудобна.

## Как оценивать свой ответ

Проверь четыре пункта: правильная формула или определение; единицы и знаки; ясное объяснение причины ошибки; границы вывода. Хороший отзыв ученику показывает, где именно рассуждение свернуло не туда, и даёт ему проверяемый следующий шаг. Например, в задаче 1 можно подставить `t=0` и взять вторую производную `h''(t)=2c=-g`.
