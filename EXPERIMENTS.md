# Разброс оценки ускорения

`explore.py` повторяет оценку по ранним 40 точкам синтетической траектории для
нескольких seed. На поздних 21 точках вычисляется MAE в метрах. Физические
параметры генератора во всех запусках одинаковы: заданное `g = 9.81 м/с²`.

```bash
python -m pip install -r requirements.txt
python explore.py
python explore.py --seeds 3 9 15 --noise-std 0.2
python explore.py --noise-std 0
python -m unittest discover -s tests -v
```

Результат исходного запуска (`noise_std=0.08 м`):

| Seed | Оценка g, м/с² | MAE на позднем участке, м |
|---:|---:|---:|
| 7 | 9.4789 | 0.0860 |
| 21 | 10.0143 | 0.0751 |
| 42 | 9.9701 | 0.0567 |

Шум меняет измеренные высоты и оценённый коэффициент при `t²`. При нулевом шуме
квадратичная модель должна восстановить заданное `g` с численной погрешностью.
Попробуй разные уровни шума и сравни диапазон оценок. Это симуляции одного закона,
а не независимые измерения ускорения в природе. Перебор seed ради самого близкого
к 9.81 результата не делает метод точнее.

Скрипт выводит только числа и не меняет файлы в `reports/` или `artifacts/`.
